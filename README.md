# Vanilla JavaScript & jQuery Interaction Lab

A collection of interactive web applications designed to master DOM manipulation, event-driven programming, and the implementation of game logic in the browser. These projects demonstrate a transition from basic scripts to complex, responsive user experiences.

## Technical Core
- **Event-Driven Architecture:** Implementing keyboard and mouse event listeners for real-time user feedback.
- **Game State Management:** Orchestrating complex logic sequences and win/loss conditions (e.g., the Simon Game logic).
- **DOM Orchestration:** Efficiently updating the UI in response to state changes using both Vanilla JS and jQuery.
- **Audio Integration:** Using the Web Audio API or HTML5 Audio elements to create immersive, interactive soundscapes.

## Featured Projects

| Project | Description | Technical Highlight |
| :--- | :--- | :--- |
| **Simon Game** | A pattern-matching memory game. | Implementation of recursive sequences and synchronized user input validation. |
| **Drum Kit** | A browser-based musical instrument. | Leveraging event delegation and CSS transitions for low-latency visual and audio feedback. |

## Skills Demonstrated
- **Problem Solving:** Translating physical game mechanics into functional JavaScript code.
- **Library Integration:** Utilizing **jQuery** for streamlined cross-browser DOM manipulation and sleek animations.
- **Asynchronous Logic:** Managing time-delayed events (e.g., `setTimeout`) to control game pacing and animations.
